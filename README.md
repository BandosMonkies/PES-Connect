## 📌 About PES Connect

**PES Connect** is a full-stack student-centric web platform designed exclusively for **PES University**.  
It combines real-time communication, academic collaboration, community discussions, and a student marketplace into a **single, unified ecosystem**.

Think of it as:

- 💬 WhatsApp / Discord → **for chats**
- 📚 Google Drive / Classroom → **for study materials**
- 🧵 Reddit → **for discussions**
- 🛒 OLX → **for student resale**
  
All tightly integrated and verified under one university platform.

---

## ⚙️ Core Features

### 💬 Real-Time Chat
- One-to-one messaging
- Group chats
- Media sharing
- Persistent conversations

### 📚 Study Materials Hub
- Upload and access notes
- Categorized by subject / semester
- Easy discoverability

### 🧵 Discussion Forum (Reddit-like)
- Topic-based posts
- Upvotes & downvotes
- Comment threads
- Anonymous participation (optional)

### 🛒 Student Resell Marketplace
- Buy & sell used items
- Books, electronics, essentials
- Student-only verified users

## 🧠 System Architecture (High Level)

- **Frontend:** Modern SPA (Client)
- **Backend:** REST API + WebSocket services
- **Chat Server:** Dedicated real-time messaging service
- **Database:** Centralized user & content storage
- **Authentication:** University-based identity (future-ready)

## 🚀 Installation & Setup

1\. Clone repo <br>
2\. Go to `client` directory <br>
3\. Run `npm install` then `npm run dev` <br>
4\. In another terminal go to `server` directory <br>
5\. Run `npm install` then `node index.js` <br>
6\. In another terminal go to `chat-server` directory <br>
7\. run `npm install` then `node index.js`
